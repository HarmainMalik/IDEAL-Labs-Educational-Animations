# IDEAL Labs — Educational Animations

Technical and educational animations created during my work as a Junior Animator at IDEAL Labs, UET Lahore.

The projects combine programming, information retrieval concepts, data visualization, and animation to explain technical topics through clear and engaging visual content.

## 🎨 About

This repository showcases educational animations and visual demonstrations developed during my experience at IDEAL Labs.

The animations were created to visually explain technical concepts that can be difficult to understand through text or static diagrams alone.

Projects include animated demonstrations of concepts related to Information Retrieval, search, similarity, clustering, and graph-based navigation.

## 👩‍💻 My Role

**Junior Animator**

**IDEAL Labs — UET Lahore**

My work involved:

- Developing educational animations for technical concepts
- Translating technical ideas into visual explanations
- Writing Python code for programmatic animations
- Creating animations using Manim
- Developing and testing animation scripts in Visual Studio
- Working with concepts related to Information Retrieval and search
- Collaborating with team members on animation content and development
- Reviewing and refining animations based on feedback
- Organizing visual content to make technical concepts easier to understand
